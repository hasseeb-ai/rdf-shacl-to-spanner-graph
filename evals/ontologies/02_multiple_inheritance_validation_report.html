Spanner Engine Invariant Verifications:
  • Label Property Signature Uniformity:
    • LABEL Person exposes exact properties (FullName, NationalId) with matching types across RegularEmployees, UndergraduateStudents, and TeachingAssistants.
    • LABEL Employee exposes exact properties (FullName, NationalId, EmployeeId, HourlyRate, EmployeeCode) identically across RegularEmployees and TeachingAssistants.
    • LABEL Student exposes exact properties (FullName, NationalId, StudentNumber, Gpa, StudentCode) identically across UndergraduateStudents and TeachingAssistants.
  • Datatype Compatibility: xsd:decimal properties (hourlyRate, gpa, stipendAmount) correctly map to NUMERIC. xsd:string correctly maps to STRING(MAX).
  • Primary Key Alignment: All physical tables use explicit surrogate UUID keys (STRING(36) NOT NULL) designated as PRIMARY KEY.
