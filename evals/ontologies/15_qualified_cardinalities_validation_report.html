4. GQL Query Cheatsheet & Engine Invariants

Pattern / Capability Spanner GQL Query Example
Polymorphic Class Query:
Query all vehicles regardless of concrete type
GRAPH VehiclePartsGraph MATCH (v:Vehicle) RETURN v.VehicleId, v.ModelName;
Polymorphic Part Query:
Query all parts belonging to any vehicle
GRAPH VehiclePartsGraph MATCH (v:Vehicle)-[:HAS_PART]->(p:VehiclePart) RETURN v.VehicleId, p.PartId, p.PartSerialNum;
Class-Specific Navigation:
Find all cars and their attached engines
GRAPH VehiclePartsGraph MATCH (c:Car)-[:HAS_PART]->(e:Engine) RETURN c.VehicleId, c.ModelName, e.PartSerialNum;
Spanner Engine Invariant Verifications:
  • Uniform Signature Rule: The :Vehicle label on Bicycles and Cars uniformly exposes (VehicleId STRING(MAX), ModelName STRING(MAX)). The :VehiclePart label on Wheels and Engines uniformly exposes (PartId STRING(MAX), PartSerialNum STRING(MAX)).
  • Referential Integrity: Edge tables (BicycleWheels, CarWheels, CarEngines) define explicit composite PKs and foreign key constraints to leaf concrete tables.
  • Qualified Cardinality Isolation: Polymorphic endpoints for abstract domain/range (ex:Vehicle → ex:VehiclePart) are resolved into discrete, type-safe join tables matching qualified restrictions.

CREATE TABLE Engines (
  PartId STRING(MAX) NOT NULL,
  PartSerialNum STRING(MAX)

CREATE TABLE BicycleWheels (

  PartId STRING(MAX) NOT NULL,
  CONSTRAINT FK_BicycleWheels_Bicycle FOREIGN KEY (VehicleId) REFERENCES Bicycles (VehicleId),
  CONSTRAINT FK_BicycleWheels_Wheel FOREIGN KEY (PartId) REFERENCES Wheels (PartId)
) PRIMARY KEY (VehicleId, PartId);

CREATE TABLE CarWheels (
  VehicleId STRING(MAX) NOT NULL,
  PartId STRING(MAX) NOT NULL,
  CONSTRAINT FK_CarWheels_Car FOREIGN KEY (VehicleId) REFERENCES Cars (VehicleId),
  CONSTRAINT FK_CarWheels_Wheel FOREIGN KEY (PartId) REFERENCES Wheels (PartId)
) PRIMARY KEY (VehicleId, PartId);

CREATE TABLE CarEngines (
  VehicleId STRING(MAX) NOT NULL,
  PartId STRING(MAX) NOT NULL,
  CONSTRAINT FK_CarEngines_Car FOREIGN KEY (VehicleId) REFERENCES Cars (VehicleId),
  CONSTRAINT FK_CarEngines_Engine FOREIGN KEY (PartId) REFERENCES Engines (PartId)
) PRIMARY KEY (VehicleId, PartId);
